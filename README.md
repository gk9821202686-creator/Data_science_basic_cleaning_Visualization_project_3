# Data_science_basic_cleaning_Visualization_project_3

Stock Market Trend & Profit/Loss Analysis

This project analyzes financial performance across four different companies over a 30-day period.

### Key Features & Workflow
1. **Data Collection & Segmentation:**
   * Gathered multi-company stock market data.
   * Filtered and split master market records into 4 dedicated company datasets.
2. **Data Cleaning & Transformation:**
   * Handled missing values, formatted timestamps, and standardized numeric columns.
3. **Financial Calculation (P/L Analysis):**
   * Computed daily and overall **Profit & Loss (P/L)** metrics by analyzing opening vs. closing stock prices.
4. **Data Visualization:**
   * Built 30-day price trend line charts comparing daily price fluctuations and closing rates across all four companies.

---

## Tech Stack

* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib
